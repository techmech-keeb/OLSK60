# OLSK60 v1 実機検証チェックリスト

QMK（VIA / Vial）へ移行した OLSK60 v1 ファームウェアを実機で確認するための手順。
ビルドはこの環境では実行できないため、**書き込み・動作確認は人手で行う**。
判定は各項目にチェックを入れ、NG があれば「メモ」に症状と該当キー／マトリクス位置を残す。

対象コントローラ: **Adafruit KB2040（RP2040）** / マトリクス 10×6（`COL2ROW`）。
配線・キー対応は [`matrix_keymap_map.md`](matrix_keymap_map.md) を基準にする。

## 0. 事前準備

- [ ] VIA 版・Vial 版の `.uf2` を用意（CI Artifacts またはリリース Assets）。
- [ ] VIA 用に `olsk60_via.json` を用意。
- [ ] ロールバック用に、書き込み前のファーム（または旧 PRK 環境）を確保。

## 1. 書き込み / ブートローダ

- [ ] RESET 2 回押し（またはブート状態で接続）で `RPI-RP2` ドライブが出る。
- [ ] `.uf2` コピー後に自動再起動し、ドライブが消える。
- [ ] 書き込み後、`_RGB` レイヤー左上（`Space` 保持 → `Esc`）の `QK_BOOT` で
      ブートローダに入れる（＝ソフトからの再書き込み経路）。
- [ ] `Esc` 押しながら接続（bootmagic）でブートローダに入れる。

## 2. USB 列挙 / 基本入力

- [ ] OS がキーボードとして認識する（VID `0x84E9` / PID `0x7960`）。
- [ ] 製品名・メーカー名の表示が想定どおり（`Techmech keys` / `OLSK60`）。
- [ ] NKRO で同時押しが取りこぼしなく入る。

## 3. 全キー・マトリクススキャン（最重要）

> `matrix_keymap_map.md` の対応表を見ながら、**全 60 キーを 1 つずつ**押して確認する。
> キーテスター（VIA の Key Tester / Vial の Matrix tester など）併用を推奨。

- [ ] 上段 `Esc 1..0 Bksp`（`[0,*]` / `[5,*]`）が正しく入る。
- [ ] 2 段目 `Tab Q..P [ \`（`[1,*]` / `[6,*]` / `\`=`[9,0]`）。
- [ ] ホーム段 `Ctrl A..L ; Enter`（`[2,*]` / `[7,*]`、`Enter`=`[7,0]`）。
- [ ] 3 段目 `Shift Z..M ,./ Up RShift`（`[3,*]` / `[8,*]`、`Up`=`[8,0]` / `RShift`=`[9,1]`）。
- [ ] 最下段 `Ctrl GUI Alt Space Fn1 Delete Fn2 ← ↓ →`
      （`[4,*]` / `[9,5..2]`）。
- [ ] **ゴースト／取りこぼしがない**（隣接同時押しで意図しないキーが出ない）。
- [ ] 位置ズレがある場合、押した物理キーと出力キー・該当 `[Row,Col]` をメモに記録。

## 4. レイヤー / モディファイア

- [ ] `Fn1`（`Enter` 保持）で `_FN`：ファンクション行 `F1..F12`、`Insert` / `PrtSc` /
      `- = [ ]` などが想定どおり。タップは `Enter`。
- [ ] `Fn2`（`Space` 保持）で `_RGB`：`Home/End/PgUp/PgDn`、RGB 操作キー。タップは `Space`。
- [ ] `LT` のタップ／ホールドが誤爆しない（連打・長押しの境界）。
- [ ] `_EXTRA`（予備・全透過）が VIA/Vial で編集可能。

## 5. RGB アンダーグロー

- [ ] 起動時に点灯（既定 breathing）。
- [ ] `_RGB` レイヤーのキーで トグル / モード / 色相・彩度・明度 / 速度が変わる。
- [ ] 21 個すべて点灯（欠け・ちらつきがない）。

## 6. VIA / Vial / Remap

- [ ] **VIA 版**: VIA でキーボードを認識。未認識時は `olsk60_via.json` を読み込んで表示。
- [ ] VIA でキーマップ編集 → 反映され、再起動後も保持される。
- [ ] **Remap**（VIA 定義利用）でも認識・編集できる。
- [ ] **Vial 版**: Vial（または Pipette）で内蔵定義を認識。
- [ ] Vial のアンロックコンボ（`Esc` + 左下 `Ctrl`）でロック解除できる。

## 7. レイアウト variant（プレート依存）

- [ ] 分割スペース版（`LAYOUT`）で最下段が図面どおり。
- [ ] 6.25U プレート採用時は `LAYOUT_6_25u`：`[4,4]` の 6.25U バーが機能し、
      `[4,3]`/`[4,5]` は非実装（押しても無反応で正常）。
- [ ] 6.25U 版はその位置を VIA/Vial で `Space` 等に割り当て直して確認。

## 8. リリース判定

- [ ] 上記すべて OK、または NG が既知の問題として文書化済み。
- [ ] ロールバック手段を確保済み。
- [ ] 既知の問題を README / リリースノートに反映。
