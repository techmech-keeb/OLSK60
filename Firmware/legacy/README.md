# Legacy firmware (旧版・使用しない)

現行のファームウェアは [`../qmk-config/`](../qmk-config/) にあります。

- **新規ビルド・出荷・更新には使用しません。** 履歴と配線情報の参照目的でのみ残しています。
- `PRK_Firmware/` … OLSK60 v1 出荷時の PRK Firmware + Remap 構成。

> This directory keeps the **legacy** firmware for reference only.
> It is **not** used for current builds. See [`../qmk-config/`](../qmk-config/) for the active firmware.
